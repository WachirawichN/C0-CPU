# Architecture
C1's architecture is based on RISC-V ISA, specifically rv32i with no extensions or custom instructions.<br>
You can find more information about rv32i on RISC-V's retified specification or [green card](https://www.cs.sfu.ca/~ashriram/Courses/CS295/assets/notebooks/RISCV/RISCV_CARD.pdf) widely available on the internet. But tl;dr, this architecture contains 33 total registers (not all of it is general purpose) and 40 instructions that can be use to program fully functions OS.
